Graphs

CausalDisco.graphs.ER_DAG(d, c, shuffle=False, rng=None)[source]

Erdős–Rényi DAG with \(cd\) expected edges: each \(i \to j\), \(i < j\), independently with probability \(2c/(d-1)\).

Parameters:

  • d – Number of nodes.

  • c – Expected number of edges per node.

  • shuffle (optional) – Randomly permute the nodes (otherwise upper triangular).

  • rng (optional) – Seed or np.random.Generator.

Returns:

Binary adjacency matrix (\(d \times d\) np.array, B[i, j] = 1 means \(i \to j\)).

CausalDisco.graphs.SF_DAG(d, c, shuffle=False, rng=None)[source]

Scale-free DAG with \(c(d-c)\) edges by Barabási–Albert preferential attachment, as in networkx.barabasi_albert_graph. Edges point from newer to older nodes, so hubs have large in-degree.

Parameters:

  • d – Number of nodes.

  • c – Number of edges per new node (integer, \(1 \leq c < d\)).

  • shuffle (optional) – Randomly permute the nodes (otherwise upper triangular).

  • rng (optional) – Seed or np.random.Generator.

Returns:

Binary adjacency matrix (\(d \times d\) np.array, B[i, j] = 1 means \(i \to j\)).

CausalDisco.graphs.count_relatives(W)[source]

Count the relatives of each node in a DAG. Idea: for every node, get set of ancestors and set of descendants; then take appropriate unions to get the relatives.

Parameters:

W – Weighted/Binary DAG adjacency matrix (\(d \times d\) np.array, W[i, j] != 0 means \(i \to j\)).

CausalDisco.graphs.get_relatives(W)[source]

Get the relatives of each node in a DAG, as a list of boolean masks.

Parameters:

W – Weighted/Binary DAG adjacency matrix (\(d \times d\) np.array, W[i, j] != 0 means \(i \to j\)).

CausalDisco.graphs.is_strongly_connected(W)[source]

Whether every node of the directed graph W (possibly cyclic) can reach every other node.

CausalDisco.graphs.reachability(W)[source]

Boolean reachability matrix R of the directed graph W (possibly cyclic), R[i, j] = (i == j or there is a directed path i -> j).

CausalDisco.graphs.sample_ER_summary_graph(p, edge_prob, rng=None, max_tries=10000)[source]

Summary graph for time series: an Erdős–Rényi digraph (each \(i \to j\), \(i \neq j\), independently with probability edge_prob, so possibly cyclic) plus a self-loop at every node, conditioned on being strongly connected. Due to the conditioning, edges are no longer independent.

Parameters:

  • p – Number of variables.

  • edge_prob – Probability of each edge.

  • rng (optional) – Seed or np.random.Generator.

  • max_tries (optional) – Maximum number of graphs to sample.

Returns:

Binary adjacency matrix of a directed, possibly cyclic graph (\(p \times p\) np.array, B[i, j] = 1 means \(i \to j\)).

CausalDisco.graphs.time_unrolled_DAG(A_summary, T)[source]

Unroll a summary graph with lag-1 edges over \(T\) time steps: A_summary[i, j] != 0 means \(i(t) \to j(t+1)\) for \(t = 0, \dots, T-2\). Node \(i\) at time \(t\) has index \(tp + i\). The Kronecker product with the \(T \times T\) shift matrix used here is a shorthand for iterating over time steps and placing A_summary in each block \((t, t+1)\).

Parameters:

  • A_summary – Weighted/Binary adjacency matrix of a directed graph, possibly cyclic and with self-loops (\(p \times p\) np.array).

  • T – Number of time steps.

Returns:

Adjacency matrix of the time-unrolled DAG (\(pT \times pT\) np.array).
