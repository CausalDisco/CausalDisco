Analytics

CausalDisco.analytics.order_alignment_ancestors(B, scores, tol=0.0)[source]

Fraction of ancestor-descendant pairs \((i, j)\), each counted once, whose scores increase in causal direction (\(s_i < s_j\), ties count \(1/2\)). This is the path-existence sortability of Reisach et al. 2023 (Appendix D.1, Equation 5). It measures agreement with the partial order implied by the graph; if that order is total, it equals \((1 + \tau_a)/2\), where \(\tau_a\) is Kendall’s tau-a between the scores and the causal order.

Parameters:

  • B – Weighted/Binary DAG adjacency matrix (\(d \times d\) np.array, B[i, j] != 0 means \(i \to j\)).

  • scores – Vector of scores (np.array with \(d\) entries).

  • tol (optional) – Tolerance threshold for score comparisons (non-negative float).

Returns:

Scalar measure of agreement between the orderings (np.nan if B has no edges).

CausalDisco.analytics.order_alignment_edges(B, scores, tol=0.0)[source]

Fraction of edges \(i \to j\) whose scores increase in causal direction (\(s_i < s_j\), ties count \(1/2\)). Allows comparing across graph sizes and differentiates between alignment, randomness, and opposite order. With ties broken uniformly at random, \((1 - v)|E|\), where \(v\) is this measure and \(|E|\) the number of edges, is the expected number of edges contradicting the order of the scores, and thus a lower bound on the expected Hamming distance between the graph and any graph compatible with that order (Reisach et al. 2026, Section 2.2).

Parameters:

  • B – Weighted/Binary DAG adjacency matrix (\(d \times d\) np.array, B[i, j] != 0 means \(i \to j\)).

  • scores – Vector of scores (np.array with \(d\) entries).

  • tol (optional) – Tolerance threshold for score comparisons (non-negative float).

Returns:

Scalar measure of agreement between the orderings (np.nan if B has no edges).

CausalDisco.analytics.order_alignment_path_lengths(W, scores, tol=0.0)[source]

Fraction of ordered pairs \((i, j)\) whose scores increase in causal direction (\(s_i < s_j\), ties count \(1/2\)), where each pair is counted once for every length \(k\) such that a directed path of length \(k\) from \(i\) to \(j\) exists. This is the definition of var- and \(R^2\)-sortability in Reisach et al. 2021 (Section 3.1) and 2023 (Equation 3).

Parameters:

  • W – Weighted/Binary DAG adjacency matrix (\(d \times d\) np.array).

  • scores – Vector of scores (np.array with \(d\) entries).

  • tol (optional) – Tolerance threshold for score comparisons (non-negative float).

Returns:

Scalar measure of agreement between the orderings.

CausalDisco.analytics.r2_sortability(X, W, tol=0.0, measure='edges')[source]

Sortability by \(R^2\).

Parameters:

  • X – Data (\(n \times d\) np.array).

  • W – Weighted/Binary ground-truth DAG adjacency matrix (\(d \times d\) np.array).

  • tol (optional) – Tolerance threshold for score comparisons (non-negative float).

  • measure (optional) – Pairs over which the order alignment is computed. One of "edges" (default; see order_alignment_edges), "ancestors" (see order_alignment_ancestors), or "path_lengths" (the definition of Reisach et al. 2021, 2023; see order_alignment_path_lengths).

Returns:

\(R^2\)-sortability value (\(\in [0, 1]\)) of the data

Parameters:

X – Data (\(d \times n\) np.array - note that the dimensions here are different from other methods, following np.corrcoef).

Returns:

Array of \(R^2\) values for all variables.

CausalDisco.analytics.rel_count_emp_hard(X, alpha=0.05)[source]

Estimate the number of relatives of each variable as the number of variables (including itself) whose correlation with it is significantly different from zero (two-sided t-test at level alpha).

Parameters:

  • X – Data (\(n \times d\) np.array).

  • alpha (optional) – Significance level for the correlation test (default 0.05).

Returns:

Array of estimated relative counts for all variables.
