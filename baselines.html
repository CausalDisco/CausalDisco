CausalDisco.baselines.sort_regress(X, scores, coef_tol=0.0)[source]

Regress each variable onto all predecessors in the ordering implied by the scores.

For each variable, the set of parents is selected by adaptive Lasso (LassoLarsIC with BIC, weights from an initial OLS fit) on the standardized data, and the returned coefficients are OLS refits of the variable onto the selected parents on the centred, original-scale data.

The selected support is invariant to rescaling the variables (exactly with sklearn’s default noise-variance estimate in LassoLarsIC, up to numerical precision). Standardization is kept for numerical conditioning, as sklearn no longer normalizes internally.

Parameters:

  • X – Data (\(n \times d\) np.array).

  • scores – Vector of scores (np.array with \(d\) entries).

  • coef_tol (optional) – Adaptive Lasso coefficients (on the standardized scale) with absolute value at most coef_tol are treated as zero.

Returns:

Candidate causal structure matrix with coefficients
